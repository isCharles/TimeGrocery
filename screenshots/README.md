# screenshots 目录说明

该目录用于存放 GitHub README 和简历展示截图。建议使用统一宽度截图，避免不同页面比例差异过大。

推荐文件：

- `home.png`：首页，展示项目名、搜索框、分类入口、推荐店铺和限时权益活动区。
- `shop-detail.png`：店铺详情页，展示店铺信息、评分、地址、热门评论和权益入口。
- `deals.png`：限时权益页，展示库存进度条、倒计时、抢购按钮和结果提示。
- `profile.png`：用户中心页，展示订单、签到、浏览记录和活跃度卡片。
- `grafana.png`：Grafana 监控页，展示接口 QPS、延迟、JVM 或缓存命中率。

截图建议：

- 桌面端宽度建议使用 1440px 或 1280px。
- 移动端可额外保存为 `home-mobile.png`。
- Grafana 截图请使用真实压测后的监控面板，不要使用虚构曲线。
